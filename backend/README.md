# MLPilot

Ask your relational database a prediction question and get a point-in-time-correct model, the SQL
that builds its inputs, and an evidence report. Self-hosted; connects read-only.

```bash
pip install mlpilot            # Python 3.13
mlpilot --help
mlpilot ui                     # the web UI on http://127.0.0.1:8000
```

The command line, the five-minute walk-through and what is and is not tested are in the
[project README](https://github.com/Harsh-Yadav-664/ML-Pilot#readme).
